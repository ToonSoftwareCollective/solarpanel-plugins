SolarPanel-app voor de Toon

SolarEdge koppelen aan je Toon

SolarEdge werkt sinds 3 november 2026 niet meer met een API-key. Je koppelt je Toon nu één keer via deze pagina; daarna houdt de Toon de koppeling zelf bij.

Je koppelcode

Vul de code direct in op de Toon. Hij is maar kort geldig en werkt één keer. Lukt het niet, haal dan hieronder gewoon een nieuwe code op.

Op de Toon: SolarPanel → instellingen → kies Solaredge en vul in:

Gebruikersnaamje Client ID
Wachtwoordje Client Secret
SiteIDje Site ID
API Keyde koppelcode hierboven

Daarna opslaan. Binnen een paar minuten verschijnt je opbrengst op de Toon.

Koppelen niet gelukt

Controleer of de redirect-URL in je SolarEdge-applicatie precies klopt (stap 1) en probeer het opnieuw.

1Eenmalig: applicatie aanmaken bij SolarEdge

  1. Ga naar developer.solaredge.com en log in met je mySolarEdge-account (hetzelfde als in de SolarEdge-app).
  2. Kies Create Application, service Monitoring API, toegang Site Access.
  3. Zet de rechten SITE_DATA en DEVICE_DATA aan.
  4. Vul bij Allowed Redirect URL precies dit adres in en klik op Save Changes:
  5. Noteer de Client ID en het Client Secret. Het Client Secret wordt maar één keer getoond; bewaar het goed.

2Koppelcode ophalen

Je gaat naar de inlogpagina van SolarEdge. Log in en klik op Approve; daarna kom je vanzelf hier terug met je koppelcode. Je Client Secret heb je hier niet nodig: dat vul je alleen op de Toon in.

3Invullen op de Toon

Zodra je terug bent, staat bovenaan deze pagina je koppelcode en wat je waar invult. Na het opslaan haalt de Toon zelf de gegevens op.

Hoe vaak wordt de opbrengst bijgewerkt?

Elke 20 minuten, alleen overdag. Met een gratis SolarEdge-account mag je 2.000 keer per maand gegevens ophalen; zo blijft de Toon daar het hele jaar onder. Het actuele vermogen is een gemiddelde over een kwartier.

Moet ik dit later opnieuw doen?

Normaal niet: de Toon vernieuwt de toegang zelf. Alleen als de Toon langer dan 30 dagen uit staat of geen internet heeft, na 24 maanden, of als je bij SolarEdge een nieuw Client Secret aanmaakt, haal je hier een nieuwe koppelcode op en vul je die in bij API Key.

Is dit veilig?

Deze pagina krijgt alleen de koppelcode te zien, en daar kan niemand iets mee zonder jouw Client Secret. Dat vul je alleen op je eigen Toon in. Er wordt niets naar een server gestuurd; alleen je Client ID wordt in je eigen browser onthouden voor de volgende keer.
